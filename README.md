# Funcionalidades
* Verificar as entradas de um arquivo csv, orgazinada (imagem,classe_id,x_min,y_min,x_max,y_max), desenhando as bounding boxes de diferentes tipos em diferentes cores, determinadas em cada linha de cada imagem. Não importa se elas estão em sequencia ou não.

# Pré-requisitos
Para rodar este projeto, você precisa ter instalado em sua máquina:
* **Python 3** (versão 3.x ou superior)
* Terminal Linux ou prompt de comando equivalente
* Opencv-python 5 (versão 5.0 ou superior)

# Como executar
A partir da pasta principal (raiz) do repositório, execute o seguinte comando no terminal:
python src/main.py
